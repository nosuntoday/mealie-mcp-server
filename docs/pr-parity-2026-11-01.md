# Upstream PR parity audit — 2026-11-01

## Scope and correction

The comparison covers all eight PRs authored by `nosuntoday`, #35–#42, at the exact heads below. The PRs remain independent contributions to the original project. This fork does not claim that upstream merged them. Other authors' PRs are outside this audit.

Version 0.2.0 used an earlier hardening snapshot. It did **not** contain the final optional ingredient flags from #38 or native source compatibility from #39. Version 0.2.1 corrects those omissions. The original MIT license and upstream history remain intact.

We fetched each PR's changed-file list, diff and complete head files, compared every changed production function/model to the fork (including cross-PR overlap), reviewed dependency and modified-fixture differences, and ran all seven newly added PR test modules against the fork. The initial unmodified test import produced **15 failures / 56 passes**: 12 real compatibility failures and 3 deliberate fork-policy differences. The affected source was corrected, and the policy tests were changed to assert the fork's actual contract, without skips or expected failures.

## Intentional differences

- **Credentials (#41):** upstream accepts authenticated admin or non-admin identities. This fork requires a verified non-admin identity and closes the client on rejection. Both cases are tested explicitly.
- **Server-local file access (#40):** `upload_recipe_image_file` and `upload_recipe_asset_file` are not registered. Their annotation tests assert absence. Lower-level upload API methods and their path checks remain; remote tools do not expose host filesystem paths. The AI tool likewise accepts text/URL, not local image paths.
- **Combined fixes:** where PRs touched the same functions, the combined behavior is retained. Mealie 3.30 step duration and weekly-plan support extends those functions. Host/origin restrictions are fork additions. Runtime dependencies retain the newer 0.2.0 lock rather than reverting unrelated packages to PR #36 versions; 0.2.1 changes only the local package version in that lock.
- **Source metadata:** the old fork tests rejecting non-HTTP `org_url` values were incorrect. This field is text metadata, not a fetch request. They were replaced by the PR's metadata preservation cases; import/image fetch URL checks remain tested. Native source-format coverage additionally exercises both URL and AI imports.
- Imported test modules have import ordering normalized. Other modified PR fixtures were compared individually: identity setup, worker-backed server fixture, sparse recipe assertions and structured-time expectations are present. Removed local-file tool tests match the deliberate tool removal.
